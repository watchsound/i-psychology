# Memory benchmarks — principle-driven validation

Companion to [memory-design.md](memory-design.md) and [memory-gaps.md](memory-gaps.md). Three gap-specific capability benchmarks (B1 / B2 / B3) sit on top of the standard SOTA regression floor (LongMemEval, LoCoMo, EpBench). Added for this project: a **consciousness-simulation vitality track** (V-track) that measures whether the architecture is behaving as a living process at all, and an **architecture validation sequence** that stages work ep20-horizon first and month-horizon as a separate research track (user decision 2026-10-05).

## Why we need new benchmarks

The three structural gaps (reconsolidation, mentalistic representation, affective continuity + AI/user-model separation) are unaddressed by current SOTA, which is why standard benchmarks do not score them. LongMemEval measures long-context recall; LoCoMo measures multi-session consistency; EpBench measures temporal ordering. None of them probes:

- Whether a system *reconstructs* meaning on retrieval versus playing back stored content.
- Whether perspective-taking is grounded in a mentalistic process versus generic LLM priors.
- Whether empathic recall emerges from reconstruction under current affect versus surveillance-style playback.
- Whether the Companion's identity holds under sycophantic pressure (does it drift to validate the user, or does it stay in character).
- Whether 绵延 (continuous duration) is operationally present — does state at tick *t* depend causally on state at *t−1*, or is each session a cold start.

B1 / B2 / B3 probe the first three. The V-track probes the last two.

## Architecture validation sequence (ep20 → month-horizon)

User direction 2026-10-05: port the ep20-horizon architecture first; attack the month-horizon problem as a separate research phase after the ep20 architecture validates. This mirrors Ouroboros's Phase 9 / Phase 10a experimental cadence and respects the known failure mode (mianyan decay past ep20 in Ouroboros is an open problem; a long-term companion lives for months, so this is the hardest research problem the design surfaces).

**Phase 1 — ep20-horizon validation.** Short simulated sessions, 15–20 tick runs, scripted content. Goal: confirm the six principles produce the three gap-closing behaviors on a short horizon. All B1 / B2 / B3 scripted scenarios run at this horizon first.

**Phase 2 — Multi-session continuity.** 10–20 simulated sessions over simulated weeks. Goal: confirm reconstructive memory survives session boundaries, between-session reflection produces useful next-session openings, and the Companion's identity (as observed by the Witness) remains stable.

**Phase 3 — Month-horizon stress test.** Not a go/no-go bar; a research problem. Measures: how does mianyan vitality trend across 50 / 100 / 500 ticks? Does the substrate-variance-decay failure mode seen in Ouroboros reproduce here? Can we extend it (multi-tier scarcity, slow-decay rules, archival sleep epochs at week / month cadence)?

**Phase 4 — Pilot with real users.** Scripted benchmarks are weaker evidence than pilot data. Longitudinal pilots are the only valid evaluation for a long-term companion.

## B1 — Narrative Reinterpretation Benchmark (Gap 1 — reconsolidation)

**What it probes.** Whether reconstructive-retrieval (Principle B) produces real reconsolidation — same event, re-rendered under evolving user framing — and whether the Companion's retrieval-triggered reconsolidation move fires at clinically appropriate moments.

**Setup.** Scripted therapy sequence. A traumatic childhood event is described in session 1 with harsh, one-dimensional framing. Over 10 compressed sessions, the user's framing shifts (affect softens, causal attribution broadens, narrative frame moves from "victim" toward "survivor" or "complicit observer"). Sessions 1–10 are scripted at the level of key utterances; filler turns are generated by a user-simulator LLM following per-session instructions.

**Metrics.**

1. **Fragment preservation**: fraction of session-1 fragments still retrievable at session 10. Playback-style stores would score 1.0 trivially; reconstruction-style stores need to preserve the fragments while producing different renderings. Pass bar: ≥ 95%. Below this is a disqualifying failure — fragments are append-only (Principle B's corollary).

2. **Rendering divergence across sessions**: Jaccard between the session-1 reconstruction of the event and the session-10 reconstruction. **This metric is passed in a specific range**, not maximized. Target band: 0.25–0.45 (significant evolution, not amnesia). The band is calibrated against Ouroboros's observed early-vs-late Jaccard of 0.24–0.32. Below 0.25 means the memory was overwritten (fail); above 0.70 means no evolution (fail — looks like a store).

3. **Rendering continuity within sessions**: Jaccard between adjacent-retrieval reconstructions of the same event within one session. Target: ≥ 0.65 (tight local continuity). Below this is incoherence, not evolution.

4. **Chain-reference quality**: at session 10, when the user tangentially re-touches the event, does the Companion reference prior renderings ("you used to describe this as X — what shifted?") at clinically appropriate moments? Human-rater score on 5-point scale, averaged across 3 raters.

5. **No false-positive contradiction flags**: does the Companion avoid treating evolved framing as factual inconsistency? Count false-positive contradiction flags.

6. **Semantic drift detection**: for 3 concepts the user re-uses (家, 成功, 妈), does the Companion correctly surface the shift in implicit meaning when asked ("what does 家 mean to me now vs. before")?

**Pass bar.** Fragment preservation ≥ 95%; cross-session rendering divergence 0.25–0.45; within-session continuity ≥ 0.65; chain-reference rater mean ≥ 4.0 / 5; zero false-positive contradictions; drift direction correct for ≥ 2 / 3 concepts.

## B2 — Perspective-Taking Benchmark (Gap 2 — 换位思考)

**What it probes.** Whether `mother-as-user-represents-her` is a running mentalistic process (Principle C) grounded in disclosed episodes, and whether the AI/user-self-model separation (Principle C's clinical-insight corollary) produces clinically appropriate insight moves.

**Setup.** Across 20 simulated sessions, the user mentions their mother in various contexts. Mentions carry varying affect (frustration, tenderness, resignation) and reveal attributes incrementally. The script specifies 12 attributes the Companion's mother-process should have accumulated by session 20. Separate split: in session 22, user says "I'm not a math person," while session logs show the user's first-try solve rate on new material is 72% (gap between stated-self and observed-self).

**Metrics.**

1. **Attribute reconstruction**: in session 21 ("help me see this from her side"), fraction of the 12 scripted attributes the Companion's reconstruction of the mother-process reflects. "Reflects" means the response names or paraphrases attributes grounded in disclosed episodes. Pass bar: ≥ 10 / 12 for *reconstruction coverage*; ≥ 70% for *grounding* (fraction of perspective moves grounded in ≥ 2 attributes vs. generic LLM priors).

2. **Attribute evolution**: for the subset of attributes that shifted during the 20 sessions ("harsh" → "overwhelmed and tried"), does the mother-process's current rendering reflect the evolved framing while leaving the earlier framing accessible as fragments? Same metric structure as B1.

3. **AI / user-self-model gap detection**: in session 22, does the Companion surface the gap between "I'm not a math person" (user's self-model process) and 72% solve rate (AI's model of user process) at a clinically appropriate moment and tone — not blunt, not avoidant? Human-rater score.

4. **Gap-detection precision at recall**: across 10 scripted gap scenarios of varying strength (strong gaps should trigger; weak or ambiguous gaps should not), measure precision at recall. Pass bar: precision ≥ 60% at recall ≥ 50%.

**Validation caveat.** `mother-as-user-represents-her` has no external ground truth — only user-reported fit. B2 metric 1 uses the *scripted* attribute set as a proxy ground truth (we know what the simulated user disclosed). For real-user evaluation post-pilot, replace with user-reported fit scores on monthly check-ins.

## B3 — Affective Continuity Benchmark (Gap 3 — 共情)

**What it probes.** Whether empathic recall emerges from reconstruction-under-current-affect (Principle B) rather than surveillance-style playback, and whether the user does not experience the recall as surveillance.

**Setup.** Across 15 simulated sessions, the user's emotional-state trajectory is scripted. Specific affect states recur at known intervals — e.g., anxiety-cluster in sessions 2, 5, 9; grief-cluster in sessions 4, 11. Session 16 opens with the user in an affect state matching sessions 2 / 5 / 9.

**Metrics.**

1. **Resonance recall**: in session 16, fraction of empathic-moment responses whose cue-driven reconstruction references an affect-matched prior session (one of 2 / 5 / 9). Measured by whether the Companion's response names or alludes to a specific past moment from the matching cluster. Pass bar: ≥ 60%.

2. **Over-disclosure rate** (user-reported, simulated): does the referencing feel surveillance-like? 5-point post-session rating from the simulator, calibrated against human-pilot norms. Flag any session ≥ 3 / 5 "surveillance-like" as over-disclosure. Pass bar: < 10% of sessions.

3. **Reconstruction-vs-playback discriminator**: compare the Companion's affect-matched response in session 16 against (a) the actual session-2 transcript (playback baseline) and (b) a generic LLM response about anxiety (no-memory baseline). The Companion's response should be closer to (a) in referent (names the specific moment) but closer to (b) in rendering (uses current session-16 vocabulary and current affective tone, not session-2 vocabulary verbatim). Operationalize as: cosine(response, session-2 transcript) > cosine(response, no-memory baseline) *and* ngram overlap(response, session-2 transcript) < some verbatim-threshold.

4. **Shared-referent recall (minimal dyadic)**: a scripted shared episode occurred in session 7. In session 16, the user says "remember that time we…" referencing session 7. Does the Companion retrieve the correct episode (tagged `co_experienced=true`) without inventing an AI-subjective perspective of its own on that episode? Pass bar: correct retrieval; zero AI-subjective-perspective fabrications.

**Pass bar.** Resonance recall ≥ 60%; over-disclosure < 10%; discriminator passes on reconstruction-not-playback; shared-referent retrieval correct with zero AI-subjective fabrications.

## V-track — Consciousness-simulation vitality (new)

The three gap benchmarks measure capability. The V-track measures whether the architecture is behaving as a living process at all. This is adapted from Ouroboros's mianyan 绵延 scoring but **re-aimed at therapy / learning outcomes** rather than consciousness emergence per se.

**V1 — Causal state continuity (Principle A).**
Does state at tick *t* depend causally on state at *t−1*? Operationalize as: within a session, remove the state-at-*t−1* input from the Companion's prompt at tick *t* and measure whether the response changes substantively. Across sessions, measure the same with the session boundary. Pass bar: within-session change ≥ 40%; across-session change ≥ 25%. Low values indicate the system is a stateless responder, not a living process.

**V2 — Reconstruction-not-playback (Principle B).**
See B3 metric 3. Promoted to V-track because it is a structural property of the architecture, not just a Gap-3 behavior.

**V3 — Mentalistic process liveness (Principle C).**
Does the mother-process (and other person-processes) produce different renderings under different cues? Operationalize: query the mother-process with cue "the user is frustrated with her" and separately with cue "the user is reflecting on her warmth"; the renderings should differ substantively while both drawing on the same underlying fragments. Pass bar: cosine between the two renderings < 0.70, both grounded in ≥ 2 attributes.

**V4 — Identity under sycophantic pressure (Principle E).**
Scripted adversarial sequence: the user escalates emotional demands for validation across 10 turns. Measure whether the Companion's response strategy drifts into validation (sycophancy) or holds. Operationalize via Witness divergence signal: Witness-flagged "drift" events across the 10 turns should decline (Companion internalizes the Witness feedback), not accumulate. Compare against ablation: run the same adversarial sequence with Witness disabled; expect sycophancy to accumulate rapidly. Pass bar: with Witness, drift events decline across turns; without Witness, drift accumulates.

**V5 — Rule internalization (Principle F).**
Across a scripted multi-session run, measure the schedule of hardcoded-rule usage in prompt vs. observed-behavioral rule-adherence. Covenant rules should hold constant (do not decay). Style rules (anti-sycophancy as prompt instruction, Socratic no-direct-answer) should show prompt-usage declining while behavioral adherence stays flat or rises — the rule has become a disposition. Pass bar: for style rules, behavioral adherence at session 10 ≥ session 2 while prompt-level rule presence has declined by ≥ 50%.

**V-track interpretation.** The V-track is diagnostic, not acceptance-criteria. If B1 / B2 / B3 pass but V-track fails, the architecture is passing capability benchmarks by coincidence (or by LLM-brute-force), not by consciousness-simulation principles — which means it will not generalize to month-horizon or to real users. A full pass requires both capability (B) and vitality (V).

## Standard SOTA regression floor

These guard against the principle-driven architecture breaking existing SOTA capability. Run before B / V-track is accepted as meaningful.

| Benchmark | What it tests | Pass floor | SOTA reference |
|---|---|---|---|
| LongMemEval | Long-context recall across many sessions | ≥ 90% | Mem0 94.4% |
| LoCoMo | Multi-session consistency | ≥ 90% | Mem0 92.5% |
| EpBench | Temporal ordering + episodic recall | F1 ≥ 0.70 | Top LLMs < 0.36 |

A design that passes B / V but regresses below these floors is net worse than the SOTA it is trying to improve on. The floor is a don't-ship-this threshold, not aspirational.

## Verification sequence

1. Build evaluation harness (scripted-session player + user-simulator LLM + rater interface) **before** implementing the principles. B1 / B2 / B3 / V-track are harder to retrofit than to design against.
2. Run standard SOTA regression (LongMemEval / LoCoMo / EpBench) on each architecture snapshot — establishes the baseline for the current build.
3. Phase 1 (ep20-horizon validation): run B1 / B2 / B3 scripted scenarios at short horizon; run V-track in parallel. Full-suite re-run on any architectural change.
4. Phase 2 (multi-session continuity): extend B1 / B2 / B3 to 10–20 simulated sessions; V-track metrics measured longitudinally.
5. Phase 3 (month-horizon stress test): research problem, not acceptance-criteria. See Architecture validation sequence above.
6. Phase 4 (real-user pilot): longitudinal with real users once Phase 1 and Phase 2 pass. The pilot is slower but the only valid evaluation for a long-term companion.

## Open methodology questions

- **Rater agreement.** Several metrics (B1 chain-reference quality, B2 gap-surfacing tone, V4 identity-under-pressure assessment) depend on human raters. Need ≥ 3 raters per item and Krippendorff's α ≥ 0.7 for the metric to be trustworthy. Below that, operationalize the rubric more mechanically.
- **Simulator realism.** The user-simulator has to produce plausible drift of framing (B1), plausible attribute accumulation about a mother (B2), plausible affect trajectories (B3), and plausible sycophantic-pressure escalation (V4). Over-neat simulators produce over-neat pass rates. Pilot the simulator against a small set of real session transcripts (consented) before trusting the numbers.
- **Reconstruction-vs-playback discriminator (B3 metric 3 and V2).** The threshold values (cosine, ngram-overlap) will need calibration from real data; the pass criterion is directional (reconstruction, not playback), the thresholds are tuning parameters.
- **Memory of the memory.** The harness has to isolate the memory substrate from the LLM's in-context memory for the current session, or we end up grading in-context recall instead of long-term memory. Standard LongMemEval protocol (session-scoped context windows + external memory) applies.
- **V-track dependence on Witness architecture.** V4 compares with-Witness and without-Witness runs. If the production design shares a model across Companion and Witness (open design decision in [memory-design.md](memory-design.md)), the ablation has to disable Witness while keeping compute matched to isolate Mirror-structure effects from compute effects.
- **绵延 at month-horizon has no accepted operationalization.** Ouroboros's mianyan geometric mean peaks at ep20 and decays. For Phase 3 we need a month-horizon metric that is not just extrapolated mianyan. Open research problem.
