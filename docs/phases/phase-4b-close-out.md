- `src/psychology_base/applications/measurement/empath_judge.py:200-227` (flagged 2026-10-07) — `_parse_empath_json` defaults to all-False on any parse failure, which produces BORDERLINE and drops that turn from the κ denominator. This is desirable for individual judge failures (a stuck LLM should not vote), but if an entire sample set triggers systematic parse failures the κ is computed on zero items and silently reports `kappa=0.0, n_items=0`. The `empath_kappa()` surface returns the `n_items` so callers can detect this, but no explicit warning is emitted. If a live-fire run exposes systematic parse failure, add a `judge_failure_rate` field to `EMPATHMathDialReport` and warn above a threshold.
